# 🎲 Pig Game

A sleek, interactive implementation of the classic Pig Game built completely **from scratch by hand** for frontend revision, then enhanced with custom UI/UX features using **Antigravity**.

🔗 **Live Demo:** [Pig Game Starter](https://r3han-01.github.io/pig-game-starter/)

---

## 🚀 Features

* **Core Gameplay Mechanics:** Standard 2-player Pig Game logic (roll dice, hold score, avoid rolling a 1).
* **Enhanced UI/UX:** Upgraded visuals, smooth layouts, and polished user interface enhancements using Antigravity.
* **Responsive Layout:** Clean CSS styling designed to work across screen sizes.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styles and modern UI improvements.
* **JavaScript (ES6+):** Game logic, state management, and DOM manipulation.

---

## 🕹️ How to Play

1. **Roll Dice:** Click the **Roll Dice** button. 
   * If you roll a **2 through 6**, the number is added to your current score.
   * If you roll a **1**, you lose your current score and your turn ends!
2. **Hold:** Click the **Hold** button to add your current score to your total score and pass the turn to the other player.
3. **Win:** The first player to reach **100 points** wins the game!
4. **New Game:** Click **New Game** at any time to reset all scores and restart.
